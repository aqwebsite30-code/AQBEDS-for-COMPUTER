## Sitemap (D3)

Generated by a static file, `public/sitemap.xml`, written once on 2026-09-26. Every URL carried the
same hardcoded `lastmod`, which is why the dates never moved. There was no generator and no database
read. Replaced in this branch by `scripts/generate-sitemap.mjs`, which runs in `npm run build` and
writes product lastmod values from `Product.updatedAt` plus one `<image:image>` per product.

## Schema (D5)

Present: Organization + WebSite on the home page, Product + BreadcrumbList on product pages,
FAQPage on /faqs, ItemList on /shop, AggregateRating inside the Product block.
Missing everywhere: `shippingDetails` and `hasMerchantReturnPolicy` on Product offers.
Defect found: the Product block's `aggregateRating` is fed the whole LocalBusiness node
(`aggregateRatingJsonLd()` in `src/lib/reviews.ts`), which is invalid — it must be a bare
AggregateRating object.
